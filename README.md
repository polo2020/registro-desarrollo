Sistema de Registro - Secretaría Ejecutiva de Desarrollo Económico
Este proyecto es una plataforma web profesional diseñada para la gestión, registro y visualización de emprendedores y empresas. Está enfocada en centralizar la información económica para facilitar la toma de decisiones y el apoyo al sector productivo.

🛠️ Tecnologías y Arquitectura
El desarrollo sigue principios de alta disponibilidad y diseño moderno:

Frontend: HTML5, CSS3 (Custom Variables), FontAwesome 6.4.0.

Fuentes: Google Fonts (Playfair Display & Inter).

Base de Datos: Firebase Firestore (NoSQL) para persistencia en tiempo real.

Diseño: Interfaz adaptativa (Responsive) con una paleta de colores institucional (Granate, Dorado y Blanco).

Certificación de Desarrollo:
@Security-Auditor, @Senior Architect, @Python Patterns

🚀 Funcionalidades Principales
El sistema se divide en dos módulos críticos:

1. Captura de Datos (index.html)
Formulario Dinámico: Validación de campos en tiempo real para RIF, teléfonos y correos.

Categorización: Clasificación por sector económico y figura jurídica.

Feedback Inmediato: Notificaciones visuales tras cada registro exitoso.

2. Gestión y Visualización (ver-registros-v2.html)
Panel de Control: Visualización de registros en formato de fichas técnicas.

Búsqueda Avanzada: Filtrado dinámico por nombre o RIF.

Gestión de Datos: Funcionalidad para eliminar registros con confirmación de seguridad (Modal).

Modo Impresión: Optimizado para generar reportes físicos de las fichas seleccionadas.
